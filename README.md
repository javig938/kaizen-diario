# Kaizen Diario

App de **mejora continua diaria** basada en el método Kaizen y el ciclo PDCA (Planificar → Hacer → Verificar → Actuar).

## Usar online

Abre: **https://javig938.github.io/kaizen-diario/**

## Instalar como app (PWA)

1. Abre el enlace en Chrome (Android) o Safari (iPhone).
2. Menú del navegador → **Instalar aplicación** / **Agregar a la pantalla de inicio**.
3. O usa el botón de instalación en la pestaña **Ajustes**.

## Funciones

- Registro diario de pequeñas mejoras (1%)
- Ideas de mejora
- Ciclo PDCA / PHVA
- Rachas y calendario de constancia
- Modo claro / oscuro
- Recordatorios diarios
- Funciona offline

## Desarrollo local

```bash
cd kaizen-diario
python3 -m http.server 8080
```

Luego abre http://localhost:8080

Los datos se guardan solo en tu navegador (localStorage).
